# Changelog

## 1.0.0

Initial release.

- **Guardian Status** — Menu bar command showing lock state with 5s polling
- **Lock Input** — Spawns guardian to lock all keyboard and mouse input
- **Wrap Command** — Lock input and run a command (auto-unlock on exit)
- **Install Guardian CLI** — One-click Homebrew install if binary not found
- **Open Logs** — Open Terminal with guardian process output
